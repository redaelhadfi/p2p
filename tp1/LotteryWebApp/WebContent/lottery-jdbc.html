🎰 Loterie avec Base de Données

ℹ️ Information

Cette version sauvegarde vos résultats dans une base de données MySQL et affiche votre historique complet de participations.

⚠️ Pré-requis:
  • MySQL Server installé et démarré
  • Base de données 'lottery_db' créée
  • Driver JDBC MySQL dans WEB-INF/lib/

📖 Consultez le fichier database/lottery_db.sql pour créer la base de données.
